# Generate Dismiss Challenges offline, on the device

**Status**: accepted

An Alarm must work with no network, at the moment it rings, with a predictable latency and a difficulty we control precisely. Dismiss Challenges are therefore generated by a local algorithm rather than fetched from an LLM or any online service. Network calls would add a failure mode (no connectivity in the morning) and uncontrollable latency to the one moment that must not fail.

## Consequences

- The challenge types available are limited to what can be generated algorithmically; richer or language-based types are deferred until they can be produced offline.
- Difficulty is expressed as an input to the local generator, which is also what Escalation drives.
